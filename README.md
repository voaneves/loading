## About the project

A single page that gathers loading animations found around the web, so you can compare them and read the code behind each one.

<p align="center">
  <a href="https://voaneves.github.io/loading/">
    <img alt="Screenshot of the loading animations page" src="https://raw.githubusercontent.com/voaneves/loading/main/assets/img/loading.png" />
  </a>
</p>

The animations are CodePen embeds by various authors; each keeps its own credit. The page is hosted on GitHub Pages.

**Demo:** <https://voaneves.github.io/loading/>

*Em português: coleção de animações de carregamento em CSS, exibidas numa página estática (PWA).*

### Technologies

HTML, CSS and JavaScript, with no dependencies.

## Features

- A variety of loading animations.
- Well-documented code for each animation.
- Static PWA page.

## Getting started

1. Clone the repository:

   ```bash
   git clone https://github.com/voaneves/loading.git
   ```

2. Open `index.html` in a web browser.
